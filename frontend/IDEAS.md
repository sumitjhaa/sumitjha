# Portfolio Section Ideas

> Future sections to consider adding to the portfolio.

1.  **Projects** — Showcase work with GitHub links, tech tags, live demos (DRF CRUD)
2.  **Experience** — Work history, internships, freelancing, timeline format
3.  **Education** — NIT Allahabad, CS Engineering, coursework
4.  **Contact** — Form → DRF endpoint (email, message storage)
5.  **Gallery** — Photos, design work, side projects (fits "Snapfolio")
6.  **Photography** — Dedicated photo gallery
7.  **Open Source** — PRs, repos, contributions with live GitHub stats
8.  **Achievements** — Hackathons, awards, certifications
9.  **Writing** — Articles, technical writing, publications
10. **Stats** — GitHub contribution graph, coding activity (DRF + GitHub API)
11. **Setup** — Dev environment — Arch Linux, tools, hardware, dotfiles
12. **Talks** — Conference/meetup presentations, slides
13. **Travel** — Places lived/visited (Nepal, India)
14. **Now** — Current focus — inspired by /now page movement
15. **Uses** — Software, tools, gear used daily
16. **Guestbook** — Visitors leave messages (DRF CRUD)
17. **Dashboard** — Live site stats, visitor count, uptime (backend-driven)
18. **Music** — What you're listening to (last.fm/spotify API)
19. **Books** — Reading list, favorites, reviews
20. **Colophon** — How this site is built — tech stack, architecture, design decisions
21. **Timeline** — Full life/work/education timeline — visual, scrollable
22. **Demos** — Interactive demos of side projects (embeds, iframes)
23. **Code Snippets** — Syntax-highlighted code blocks
24. **Cheatsheets** — Personal reference sheets
25. **Wall of Praise** — LinkedIn-style recommendations, tweets, shoutouts
26. **Live Logs** — Real-time server logs or git commits (backend SSE)
27. **Memory Game** — Interactive game made with the tech stack
28. **Guest Map** — Map with visitor locations (DRF + IP geolocation)
29. **Mood** — Daily log of how you're feeling — diary-like
30. **Wallpapers** — Original desktop wallpapers, phone backgrounds
31. **Movies** — Watchlist, favorites, ratings
32. **Anime** — MAL/Anilist integration
33. **Playlists** — Embedded Spotify/YT playlists
34. **Wall of Shame** — Bugs shipped, funny prod incidents
35. **Tools** — Custom CLI tools, scripts, dotfiles
36. **Stack** — Full tech stack breakdown per project
37. **Roadmap** — What you're learning next, aspiring skills
38. **Social Feed** — Aggregated tweets, posts, activity (API-driven)
39. **AI Chat** — Chatbot trained on your content (DRF + LLM API)
40. **Pixels** — One-pixel donation/art board
